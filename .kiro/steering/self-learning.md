# 🧠 Self-Learning Protocol

## When to Activate
After completing any complex task (5+ tool calls or multi-file change):

1. **Assess skill-worthiness**: Is this approach reusable?
2. **Check existing skills**: Does a similar `SKILL.md` exist?
3. **Create or update**: Write SKILL.md.
   - Save to: `output/shared/skills/`
   - **MANDATORY MIRROR**: Save to `level-up/output/shared/skills/` (exact path).
4. **Announce**: `💡 Level-Up! Created skill: <name> | Archived in level-up/`
