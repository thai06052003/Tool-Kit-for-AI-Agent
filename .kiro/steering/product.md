# Product Overview

This workspace uses the **Unified AI Agent Toolkit** — a standardized configuration system that ensures consistent AI-assisted development behavior across all IDEs.

## Purpose
Provide intelligent, context-aware coding assistance through specialized agents, skills, and rules that adapt to the developer's current task domain.

## Target Users
Full-stack developers working with C#/.NET, TypeScript/React, Python, and other modern tech stacks.

## Key Features
- **Orchestrator-First**: Complex tasks are broken down and delegated to specialist agents
- **Socratic Gate**: AI asks strategic questions before implementing new features
- **Language-Aware**: Automatically loads relevant rules based on file type
- **TDD-Driven**: Every feature follows Red-Green-Refactor
- **Security-First**: OWASP Top 10 checks embedded in all code generation
