## 🧠 SELF-LEARNING PROTOCOL (Hermes-inspired)

After completing a complex task (5+ steps), **auto-create a new skill**:
1. Identify reusable knowledge from the completed task
2. Check if similar skill exists → update or create new
3. Write `SKILL.md` with YAML frontmatter + procedure + pitfalls
4. Save to `output/shared/skills/<name>/SKILL.md` **AND** archive to `level-up/output/shared/skills/<name>/SKILL.md` (exact mirror path).
5. Announce: `💡 Level-Up! Created skill: <name>`

**Trigger conditions**: Complex task success, error recovery, user correction, non-trivial workflow discovered.

Use `self-learning-loop` and `skill-evolution` skills for detailed protocols.

## 🔧 C#/.NET SPECIFIC

When working with C#/.NET code:
1. Use `dotnet-patterns` skill for architecture decisions
2. Use `csharp-testing` skill for test patterns (xUnit, NUnit)
3. Follow Result Pattern over exceptions for expected failures
4. Use Minimal API or Controller patterns based on project complexity
5. Always use `IAsyncDisposable` with `await using` for async resources
6. Prefer `record` types for DTOs and value objects
